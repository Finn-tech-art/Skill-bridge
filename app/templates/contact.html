Contact

Need help with SkillBridge?

This page provides public context for users, reviewers, and maintainers who need to understand how to reach the team responsible for the current SkillBridge deployment.

Current support model

Project-maintainer support during the active pilot phase

SkillBridge is currently operating as an actively maintained project deployment. At this stage, support is handled directly by the project owner or deployment maintainer rather than through a dedicated commercial support desk.

For account issues, product questions, or verification requests, use the same official channel through which this SkillBridge deployment was shared with you, or the project repository and maintainer contact associated with the deployment.

What this page is for

Public reference for trust, review, and policy questions

This page exists so that users and external reviewers can understand that SkillBridge is a real product deployment with visible ownership context, platform policies, and a documented support path. It should be read together with the About, Privacy, and Terms pages.

Account help

If you are having trouble signing in, confirming your email, or accessing a profile, first make sure you are using the correct SkillBridge domain and the same email address you used during registration. If the issue persists, contact the project maintainer through the official project channel.

Policy and trust concerns

If you need clarification about platform behavior, privacy expectations, identity verification, or public review status, refer to the documentation pages linked in the footer and then escalate through the project maintainer if needed.

Future contact improvements

As SkillBridge moves further toward production readiness, this page should be updated with a dedicated support email address, a formal point of contact, and any relevant organizational details for the platform owner or team.
